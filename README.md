# AVUS FIT — Landing Page Fitness

**Força. Foco. Resultado.**

Uma experiência digital desenvolvida para o segmento fitness, com foco na apresentação de uma academia premium, divulgação de modalidades e captação de novos alunos.

## Sobre o projeto

O Avus Fit é um projeto de apresentação digital desenvolvido para o segmento fitness, explorando uma identidade visual moderna e uma experiência de navegação orientada à conversão.

A landing page foi estruturada para apresentar a proposta da academia, destacar sua infraestrutura, divulgar modalidades de treinamento e apresentar planos de adesão.

O objetivo é transformar a presença digital em um canal de atração de novos alunos, facilitando o acesso às informações e o contato comercial.

## Funcionalidades

- **Apresentação institucional:** destaque para a identidade e proposta da academia.
- **Estrutura:** apresentação visual dos ambientes e equipamentos.
- **Modalidades:** divulgação de musculação, treinamento funcional, cardio e personal trainer.
- **Resultados:** seção visual dedicada à apresentação de transformações e evolução física.
- **Planos e mensalidades:** comparação entre diferentes modalidades de adesão.
- **Tema claro e escuro:** alternância de aparência com preferência salva no navegador.
- **Menu responsivo:** navegação adaptada para dispositivos móveis.
- **Animações de entrada:** elementos que aparecem conforme a rolagem da página.
- **Contadores animados:** apresentação dinâmica de indicadores.
- **Captação de contatos:** formulário para identificação do interessado e seleção de plano.
- **Integração com WhatsApp:** preparação de mensagens personalizadas para agendamento de visitas.

## Identidade visual

A proposta visual combina elementos do universo esportivo com uma estética contemporânea e minimalista.

A identidade utiliza:

- Tipografia expressiva para títulos e chamadas.
- Contraste entre superfícies claras e escuras.
- Azul como cor de destaque.
- Imagens de alta qualidade relacionadas ao universo fitness.
- Animações sutis para reforçar a experiência de navegação.

## Tecnologias utilizadas

| Tecnologia | Aplicação |
|---|---|
| HTML5 | Estrutura e organização do conteúdo |
| CSS3 | Estilização e animações personalizadas |
| JavaScript (Vanilla) | Lógica e interatividade |
| Tailwind CSS | Estilização e responsividade |
| Google Fonts | Tipografia Barlow Condensed e DM Sans |

## Experiência do usuário

O desenvolvimento prioriza uma navegação intuitiva, responsiva e orientada à conversão.

A estrutura conduz o visitante por uma jornada que apresenta a academia, demonstra seus diferenciais, compara os planos disponíveis e facilita o contato para agendamento de uma visita.
